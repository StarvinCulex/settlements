# Project Overview
This is a Minecraft mod based on Neoforge 1.21.4.
The main features of this mod include:

- Town & Building System
  - [x] Implement block placement of buildings in the world, with dynamic style/appearance updates.
  - [x] Buildings continue to perform various production functions using logic that runs independently of chunk loading.
- Folk (Resident) System
  - [ ] Serves as active agents that perform behaviors and interactions between buildings.
        (Planned to support richer actions and animations in the future.)

Progress legend: [x] = completed, [ ] = planned / not implemented yet
